# Carrier Discovery

This folder contains the first analysis step of the **Measurable Science** project.

The script scans all normalized measurements in its folder and automatically searches for the most interesting frequency bands.

You do **not** need to tell the script where the carrier should be.

It performs a blind search and reports the frequency bands that deserve further investigation.

---

# How to use

1. Copy one or more normalized CSV files into this folder.
2. Run the script.
3. Wait for the analysis to finish.

The script will automatically analyze every CSV file it finds.

---

# Output

The script produces:

- terminal summary while the analysis is running;
- **PLV_CARRIERS_ALL_SITES.csv** containing the final results.

The CSV file contains the candidate frequency bands that showed the strongest and most consistent phase organization.

These frequencies become the starting point for the next step of the project.

---

# What should I do next?

The discovery script only tells you **where to look**.

It does not describe the carrier itself.

Choose one of the reported frequency bands and continue with the scripts contained in the **Carrier Characterization** folder.

---

# Do I need to understand the code?

No.

Most people will not.

If you are unsure what the results mean, simply open your preferred AI assistant and provide:

- your normalized CSV file;
- the output generated by this script;
- the script itself if necessary.

Ask questions such as:

- Which frequency bands look most interesting?
- Why was this frequency selected?
- What does PLV mean?
- What should I investigate next?

Modern AI tools can explain every step of the analysis.
