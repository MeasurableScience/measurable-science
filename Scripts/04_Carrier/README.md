# Carrier Characterization

This directory contains the second step of the **Measurable Science** methodology.

Once a candidate carrier has been discovered, this script performs a detailed analysis of its properties.

The script measures characteristics such as:

- amplitude;
- phase relationships;
- polarization;
- principal oscillation axis;
- temporal stability;
- phase dynamics.

The objective is to describe the carrier as completely as possible before attempting to interpret its behavior.

---

# Why is the carrier important?

Within the model proposed in the accompanying book, the carrier represents the primary wave of the natural computational system in which we live.

According to this model, every measurable process is expressed through the carrier.

For this reason, understanding the carrier itself is considered the first step.

Only after the carrier has been identified and characterized does it become meaningful to investigate the information carried by its modulations.

---

# What comes next?

Carrier characterization is not the final goal.

It is only the foundation for the analyses that follow.

Future scripts in this repository investigate the modulations present on the carrier.

Within the proposed model, these modulations represent the communication layer of the system.

They are hypothesized to describe interactions between living organisms, the environment and the phenomena traditionally studied as separate systems.

Whether these ideas are supported by future measurements is left to experimental verification.

---

# Do I need to understand all the mathematics?

No.

Run the script and examine the generated report.

If you are unsure what the results mean, simply provide the output together with your data to your preferred AI assistant.

Modern AI tools can explain every reported parameter and help interpret the measurements.

# Future Measurements

The model proposed in the accompanying book predicts that this type of field should not be unique to Cappadocia.

If the interpretation is correct, similar corridors should exist between other neighboring carrier regions.

Measurements collected so far suggest that neighboring carriers exhibit different phase relationships. Within the proposed model, the interaction between adjacent carriers may produce the vertically oriented dynamic structures investigated in this directory.

Several additional regions have already been identified as potential candidates.

The next step is simple:

If you live in one of these regions, or have the opportunity to visit them, we encourage you to make your own measurements.

All recording scripts, normalization tools and analysis software required to reproduce this methodology are included in this repository.

Independent measurements are far more valuable than additional theoretical discussion.

If your results differ from those presented here, that is equally important.

Every well-documented measurement helps improve our understanding of the observed field.

If you would like to contribute your recordings, please open an issue or contact the project so the data can be analyzed and compared with existing measurements.
