# Carrier

The **Carrier** is the foundation of the **Measurable Science** model.

Everything described throughout this project depends on one simple question:

**Does a naturally occurring planetary carrier exist?**

If the answer is **no**, the entire model presented in this project becomes invalid.

For this reason, the existence of the Carrier became the first question investigated through field measurements.

---

## Why Measure It?

If the proposed Carrier is real, it should not appear only under special conditions.

It should be present continuously.

It should be measurable:

- on mountain summits;
- inside caves;
- at archaeological sites;
- in forests;
- in open fields;
- across different countries;
- everywhere the same planetary system exists.

If a Carrier cannot be detected repeatedly under real-world conditions, there is no reason to continue developing the model.

---

## The Proposed Model

According to the proposed model, the planetary system is organized around **four primary Carriers**.

The boundaries between neighbouring Carriers form the proposed **Main Lines (Magistrale).**

Unlike an artificial radio transmitter, the Carrier is proposed to be a natural resonant structure rather than a perfectly stable frequency source.

Measurements collected throughout this project suggest a dominant resonance close to **7.8 Hz**, with small natural variations expected in every natural system.

---

## What Is Being Measured?

The objective is not to search for one exact frequency.

Instead, the project investigates:

- resonance;
- stability;
- phase;
- repeatability;
- geographical continuity.

If the same characteristics can be measured repeatedly at different locations, the Carrier model becomes stronger.

If they cannot, the model must be reconsidered.

---

## Current Status

The Carrier remains a working hypothesis.

Every new measurement either strengthens, modifies or challenges the model.

Ultimately, the Carrier will be judged only by one criterion:

**Can it be measured repeatedly under real-world conditions?**
