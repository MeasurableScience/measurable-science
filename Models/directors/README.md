# Directors

The **Director** is one of the functional components of the **Measurable Science** model.

According to the proposed model, Directors do not generate the Carrier or the emitted phenomena.

Instead, they regulate the interaction between them.

---

# Function

Within the proposed model, a Director determines how the local Carrier responds to the emission produced by an Emitter.

Rather than generating energy, the Director provides the instructions that organize how that energy is used.

Using a computer analogy, the Director performs a role similar to a controller, coordinating the operation of the system.

---

# Role in the System

The proposed planetary system is not viewed simply as a collection of independent structures.

Instead, it is interpreted as an organized system in which each component performs a specific function.

Within this organization:

- Carriers provide the structural framework;
- Main Lines provide communication pathways;
- Emitters generate localized electromagnetic phenomena;
- Directors determine how those emissions interact with the local Carrier.

Together, these components form the functional architecture of the proposed model.

---

# Current Status

The Director model remains a working hypothesis.

Its purpose is to explain the organization of measurable emissions observed at different locations.

As additional measurements become available, the model will continue to evolve.

Ultimately, the Director model will be evaluated by its ability to explain repeatable observations and generate testable predictions.
