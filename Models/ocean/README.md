# Ocean Model

The **Ocean Model** investigates whether large-scale ocean circulation is consistent with the geometry proposed by the **Measurable Science** model.

According to the proposed model, the central planetary structure should influence not only measurable electromagnetic phenomena but also the long-term organization of the world's oceans.

Rather than relying solely on theoretical descriptions, this project analyzes publicly available oceanographic measurements collected by scientific monitoring networks.

The objective is to determine whether large-scale ocean circulation exhibits patterns consistent with the proposed geometry of the model.

---

# Data Sources

This project primarily uses publicly available measurements collected by established scientific institutions.

Examples include:

- NOAA (National Oceanic and Atmospheric Administration)
- NASA Ocean Color Program
- Copernicus Marine Service (CMEMS)
- Global Drifter Program (GDP)
- Argo Float Program
- National Data Buoy Center (NDBC)
- Integrated Marine Observing System (IMOS)

Additional datasets may be incorporated as they become available.

---

# Analysis

The objective is not to reinterpret existing oceanographic measurements, but to analyze them from a different perspective.

Ocean current measurements, drifting buoys, sea surface temperature, wave motion and other publicly available datasets are compared with the predictions of the proposed planetary model.

Particular attention is given to identifying large-scale circulation patterns that may correspond to the proposed four-region geometry of the system.

All analyses are performed using the scripts contained elsewhere in this repository.

---

# Current Status

The Ocean Model remains under active development.

As additional datasets become available, the proposed model will continue to be tested, refined or rejected according to the observations.

Ultimately, the value of the model depends on one question:

**Do independently collected oceanographic measurements exhibit repeatable large-scale patterns consistent with the proposed planetary geometry?**
