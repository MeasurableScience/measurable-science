# Main Lines (Magistrale)

This directory supports the proposed **Main Lines (Magistrale)** model described in the accompanying book.

Because continuous Main Line recordings are very large (hundreds of megabytes or several gigabytes), the raw datasets are **not stored directly in this GitHub repository**.

Instead, this document provides a link to the original raw recording hosted in the **Measurable Science Raw Data Archive** on Google Drive.

The theoretical background, the significance of this measurement and its relation to the proposed model are explained in detail in the accompanying book.

The methodology used to acquire these measurements is described in the **Methodology** section of this repository.

# Open Research

The purpose of publishing these recordings is to allow anyone to independently verify, challenge or improve the proposed Main Line model.

Independent measurements, analyses and constructive criticism are always welcome.
