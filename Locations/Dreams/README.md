# Dreams

This directory contains representative overnight recordings supporting the proposed **Dream** model.

The complete theoretical background, the motivation for these measurements and their relation to the overall model are presented in the accompanying book.

This repository complements the book by providing representative raw datasets for independent analysis.

---

# Relation to the Book

The accompanying book explains the proposed Dream model and discusses the observations that motivated these recordings.

The purpose of this directory is not to explain the theory, but to provide direct access to representative raw measurements so they can be independently analyzed.

---

# Representative Measurements

The datasets included here represent overnight recordings collected during normal sleep.

Only representative recordings are included in this repository.

Additional recordings may be added as the project continues.

---

# Field Measurements

All recordings were acquired following the methodology described in the **Methodology** section of this repository.

For details regarding:

- recording conditions;
- acquisition procedure;
- recording duration;
- recommended measurement practices;

please refer to the methodology documentation.

---

# Raw Data

The datasets are published exactly as recorded.

No filtering, preprocessing or interpretation has been applied beyond extracting the frequency range investigated in this project.

The scripts used to produce these datasets are available in the **Scripts** directory of this repository.

Researchers are encouraged to analyze the recordings using either their own methods or the provided scripts.

---

# Open Research

The purpose of publishing these datasets is to allow anyone to independently verify, challenge or improve the proposed Dream model.

Independent measurements, analyses and constructive criticism are always welcome.
