# Locations

The **Locations** directory contains representative field measurements collected as part of the **Measurable Science** project.

Rather than being organized by country or geographical region, locations are grouped according to the part of the proposed model they are intended to investigate.

This organization reflects the scientific objective of the project: each field expedition is designed to test one or more specific model components.

---

# Directory Structure

Locations are grouped into the following categories:

- **Carrier**
- **Main Lines (Magistrale)**
- **Emitters**
- **Directors**
- **Dreams**
- **Ocean Model**

Each category contains representative field measurements related to that particular model.

---

# Representative Measurements

Each category includes:

- a description of the investigated model;
- the reason why the locations were selected;
- representative raw measurement files;
- photographs of the measurement setup (when available);
- notes describing the recording conditions.

Only representative datasets are included in this repository.

The complete measurement archive is significantly larger and continues to grow through ongoing field work.

---

# Minimum Requirements

To allow independent verification, every contributed measurement should include at least:

- location name;
- date and time;
- photographs of the measurement setup (when possible);
- raw measurement files (CSV, WAV or other supported formats);
- a short description of the recording conditions.

Additional documentation is always welcome.

---

# Data Analysis

Raw measurements are intentionally separated from data analysis.

All processing, visualization and signal analysis are performed using the scripts contained in the **Scripts** directory.

Researchers are encouraged to analyze the published raw data using either the provided scripts or their own methods.

---

# Open Research

All representative measurements are published to encourage independent verification and collaboration.

Researchers are welcome to repeat measurements, compare results and contribute additional datasets following the same documentation standards.
