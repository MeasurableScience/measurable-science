# Ocean Model

The proposed Ocean Model is described in detail in the accompanying book.

This directory does not contain raw datasets because the analyses presented in the project are based entirely on publicly available scientific oceanographic databases.

The purpose of this document is to provide references to the original data sources used throughout the project.

All data processing and analysis scripts are available in the **Scripts** directory of this repository.

---

# Public Oceanographic Data Sources

The analyses presented in the book make use of publicly available measurements obtained from international oceanographic research programs, including:

- **PANGAEA**
  https://www.pangaea.de/

- **Argo Program**
  https://argo.ucsd.edu/

- **NOAA National Centers for Environmental Information (NCEI)**
  https://www.ncei.noaa.gov/

- **Copernicus Marine Service**
  https://marine.copernicus.eu/ :contentReference[oaicite:0]{index=0}

- **Integrated Marine Observing System (IMOS)**
  https://imos.org.au/ :contentReference[oaicite:1]{index=1}

Additional publicly available datasets may also be used where appropriate.

---

# Data Analysis

This repository does not redistribute datasets that are already freely available from the original scientific providers.

Instead, the analysis scripts used throughout the project are provided in the **Scripts** directory.

Researchers can download the original datasets directly from the sources listed above and reproduce every analysis independently.

---

# Relation to the Book

The accompanying book explains:

- why these datasets were selected;
- how they relate to the proposed Ocean Model;
- how they compare with the predictions of the proposed four-Carrier model.

The purpose of this repository is to provide complete transparency by allowing anyone to reproduce the analyses using the original publicly available datasets.

---

# Open Research

All datasets referenced by this project are publicly available.

Researchers are encouraged to download the original measurements, execute the provided scripts, verify the published analyses and develop their own independent interpretations.
