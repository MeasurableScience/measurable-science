# Directors

This directory contains representative raw measurements supporting the proposed **Director** model.

The complete theoretical description of Directors, together with their proposed function within the overall model, is presented in the accompanying book.

This repository complements the book by providing representative raw datasets for independent analysis.

---

# Relation to the Book

The book introduces the proposed Director model and explains why these particular locations were selected for investigation.

The datasets published here correspond to those discussed throughout the book and allow readers to independently examine the measurements on which the proposed model is based.

The objective of this directory is not to explain the theory, but to provide direct access to the original field recordings.

---

# Representative Measurements

The datasets included here represent measurements collected at locations proposed to function as Directors within the model.

Only representative recordings are included in this repository.

The complete measurement archive is considerably larger and continues to grow through ongoing field work.

---

# Field Measurements

All measurements were acquired following the methodology described in the **Methodology** section of this repository.

For details regarding:

# Raw Data

This directory intentionally contains only representative raw measurements.

No filtering, preprocessing or interpretation is included.

Researchers are encouraged to analyze these datasets using either their own methods or the scripts provided in the **Scripts** directory.

---

# Open Research

The purpose of publishing these datasets is to allow anyone to independently verify, challenge or improve the proposed Director model.

Independent measurements, analyses and constructive criticism are always welcome.
