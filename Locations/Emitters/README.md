# Emitters

This directory contains representative raw measurements supporting the proposed **Emitter** model.

The complete theoretical description of Emitters, their proposed function and the reasons why these particular locations were selected are presented in the accompanying book.

This repository complements the book by providing representative raw datasets for independent analysis.

---

# Relation to the Book

The book explains the proposed Emitter model and discusses why the selected locations are considered important within the overall system.

The datasets published here correspond to measurements discussed throughout the book and allow readers to independently examine the original field recordings.

The purpose of this directory is not to explain the theoretical model, but to provide direct access to representative raw measurements.

---

# Representative Measurements

The datasets included here represent measurements collected at locations proposed to function as Emitters.

According to the proposed model, different Emitters are expected to produce different emissions depending on their role within the system.

Only representative recordings are included in this repository.

The complete measurement archive is considerably larger and continues to grow through ongoing field work.

---

# Field Measurements

For details regarding:

- recommended recording practices;

# Raw Data

This directory intentionally contains only representative raw measurements.

No filtering, preprocessing or interpretation is included.

Researchers are encouraged to analyze these datasets using either their own methods or the scripts provided in the **Scripts** directory.

---

# Open Research

The purpose of publishing these datasets is to allow anyone to independently verify, challenge or improve the proposed Emitter model.

Independent measurements, analyses and constructive criticism are always welcome.
