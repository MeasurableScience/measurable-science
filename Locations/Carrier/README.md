# Carrier

This directory contains representative raw measurements supporting the proposed **Carrier** model.

The complete theoretical description of the Carrier, together with the reasoning behind the selected locations, is presented in the accompanying book.

This repository is intended to complement the book by making representative raw datasets publicly available for independent analysis.

---

# Relation to the Book

The book introduces the proposed Carrier model and explains why these particular locations were selected for investigation.

The datasets published here correspond to those discussed throughout the book and allow readers to independently examine the measurements on which the proposed model is based.

The objective is not to replace the theoretical discussion presented in the book, but to provide direct access to the original field recordings.

---

# Representative Measurements

The datasets included here represent measurements collected from multiple geographical regions.

Only representative recordings are included in this repository.

The complete measurement archive is considerably larger and continues to grow through ongoing field work.

---

# Field Measurements

All measurements were acquired following the methodology described in the **Methodology** section of this repository.

For details regarding:

- sensor placement;
- recording conditions;
- calibration;
- field procedures;
- recommended recording practices;

please refer to the methodology documentation.

---

# Raw Data

This directory intentionally contains only representative raw measurements.

No filtering, preprocessing or interpretation is included.

Researchers are encouraged to analyze these datasets using either their own methods or the scripts provided in the **Scripts** directory.

---

# Open Research

The purpose of publishing these datasets is to allow anyone to independently verify, challenge or improve the proposed Carrier model.

Independent measurements, analyses and constructive criticism are always welcome.
