# WitMotion WT901

## Introduction

The WT901 became the primary measurement device used throughout the **Measurable Science** project.

Most measurements presented in this repository were recorded using this sensor.

It combines a three-axis accelerometer, gyroscope and magnetometer into a compact, inexpensive module that can be connected directly to a computer.

---

# Why WT901?

Only a few years ago, obtaining a sensor capable of recording this combination of measurements required significantly more expensive hardware.

Today, modules such as the WT901 make this technology available to students, hobbyists and independent researchers for only a small fraction of the historical cost.

This dramatic reduction in price has made scientific experimentation accessible to almost anyone.

---

# Connection

Earlier versions of the WT901 required:

- USB-to-TTL adapter
- jumper wires
- separate power connection

This was the configuration used during the original measurements performed for this project.

Today, inexpensive integrated USB cables are widely available and are recommended for new users because they simplify installation considerably.

Most of these cables already contain the required USB-to-TTL converter inside the cable itself.

They are inexpensive and can easily be purchased from online marketplaces such as AliExpress.
