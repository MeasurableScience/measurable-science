# Methodology

## Introduction

The purpose of this directory is to document the methodology used throughout the **Measurable Science** project.

This is not a laboratory protocol.

It is a practical field methodology developed over many years of independent research, travel and experimentation.

The objective is simple:

**Collect reliable measurements under real-world conditions and document them well enough that another researcher can repeat the same investigation.**

Every expedition, every location and every recording presented in this project follows the same basic philosophy:

Measure first.

Analyze later.

---

# Why I Started Measuring

Every research project begins with a question.

The question that started this project was remarkably simple.

If the model described throughout this project is correct, then the structures it proposes should not exist only as philosophical concepts or ancient traditions.

They should produce measurable effects.

If they are real, they should be measurable almost everywhere.

They should not require billion-dollar laboratories or highly specialized scientific facilities.

They should be detectable using affordable equipment, provided the measurements are carefully planned and properly documented.

This simple idea became the foundation of the **Measurable Science** project.

The purpose of every expedition is not to prove the model.

The purpose is to determine whether the environment itself contains measurable signatures that can later be compared, analyzed and independently verified.

---

# Planning

Every expedition begins with one simple question:

**Where should the next measurements be performed?**

Locations are rarely selected at random.

Instead, I look for places where several independent observations point toward the same location.

Examples include:

- local legends;
- historical traditions;
- ancient place names;
- archaeological sites;
- unusual geographical formations;
- historical maps;
- previous measurements.

These observations are **not treated as scientific evidence**.

They are simply practical reasons to visit a location and perform measurements.

The measurements themselves determine whether a location deserves further investigation.

For example, mountains associated with the Sun, the Moon or particular stars, places described as sacred, locations known as "pillars of heaven", pyramid-shaped hills or important archaeological sites are all considered interesting candidates for field research.

The more independent observations that point toward the same location, the stronger the motivation to include it in a future expedition.

---

# Field Measurements

Once the location has been reached, the objective becomes collecting the best possible dataset.

Many locations require several hours of hiking before measurements can begin.

Some summits require an entire day to reach.

When a location has finally been reached, every effort is made to collect as much useful data as possible before leaving.

Whenever practical:

- the sensor is aligned with the cardinal directions;
- the measurement setup is photographed;
- GPS coordinates are recorded;
- several independent recordings are performed.

As a general recommendation, at least three recordings of approximately ten minutes each are collected.

Whenever time and conditions allow, one longer continuous recording is also made.

Field conditions are rarely perfect.

Wind, rain, temperature, difficult terrain and limited daylight are all part of real field research.

Measurements are therefore performed under the best conditions available at that moment.

The objective is always to return with the best possible dataset.

---

# Long-Distance Measurements

Some investigations focus on individual locations.

Others investigate gradual changes observed across large geographical regions.

In these cases, measurements are collected while travelling between predefined locations.

Whenever an unexpected place appears particularly interesting, additional measurements are often performed before continuing the journey.

Some of the most valuable datasets contained in this project were collected in this way.

---

# Documentation

Every measurement should be documented as completely as practical.

Whenever possible, documentation includes:

- photographs;
- GPS coordinates;
- date and local time;
- equipment used;
- sensor orientation;
- recording duration;
- notes describing the surrounding environment.

Good documentation often becomes just as valuable as the measurements themselves.

---

# Measure First — Analyze Later

Field expeditions are dedicated to collecting data.

Data analysis is intentionally postponed until after returning from the field.

Once back home, every recording can be examined carefully under controlled conditions using the analysis scripts provided elsewhere in this repository.

Separating field work from data analysis allows valuable expedition time to be spent collecting measurements rather than interpreting them.

Many analyses require days or even weeks of careful comparison between measurements collected at different locations.

That work is best performed after the expedition has ended.

---

# Reproducibility

The objective of this methodology is not to describe one person's way of working.

Its purpose is to document the research process well enough that another researcher can repeat the same investigation using similar or completely different equipment.

Scientific progress depends on independent observations that can be repeated.

Every measurement presented in this project is intended to move one step closer to that goal.
