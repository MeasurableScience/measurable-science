# References

This repository contains the supporting references used throughout **Measurable Science**.

Instead of filling the book with long citations and bibliographies, each significant statement is linked to a dedicated reference page in this repository.

Every reference page documents the original source behind a statement, making it easy for readers to verify the information, access the original publication whenever possible, and understand how that source is used within the book.

## Standard Reference Structure

Every reference follows the same format:

```text
# Title

## Statement in the Book

The statement or claim to which this reference applies.

## Sources

- Books
- Scientific papers
- Government publications
- Official datasets
- Historical documents
- Other reliable sources

## Original Publications

Original publication details, including author(s), publication year, journal, publisher, DOI, ISBN, or official URL whenever available.

## Additional Notes

Optional comments, historical context, licensing information, or other relevant details.

## Used in

Chapter(s) and section(s) of *Measurable Science* where this reference is cited.
```

## Purpose

The purpose of this repository is transparency.

Readers should never have to rely solely on quotations or interpretations. Whenever possible, they can examine the original sources themselves and reach their own conclusions.

This repository will continue to grow alongside the book as additional references are added.
