# Reference 011 — Electron Capture

## Purpose

Reference for electron capture discussed in *Merljiva Nauka*.

## Electron capture

Electron capture is a radioactive decay process in which an atomic
electron is captured by a proton in the nucleus.

The proton is transformed into a neutron and an electron neutrino
is emitted:

p + e⁻ → n + νₑ

The atomic number of the resulting nucleus decreases by one, while
the mass number remains unchanged.
