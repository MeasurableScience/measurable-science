# Measurable Science

An open scientific research project focused on reproducible measurements, transparent methodology, affordable scientific instrumentation and independent verification.

All measurements, software, documentation and methodology are published openly so that anyone can reproduce, verify or challenge the results.

# About the Project

**Measurable Science** is the result of years of independent research that began with a simple principle:

> Accept nothing as true simply because it is widely believed.  
> Accept nothing as false simply because it challenges established ideas.

The purpose of this project is not to ask the reader for belief.

Its purpose is to present a model, explain the reasoning behind it, and publish the measurements, analyses and methodology that led to its development.

Throughout this research I combine ideas from science, philosophy and religious traditions—not as unquestionable authorities, but as different perspectives that may help explain the same reality.

Every conclusion presented in the book is intended to be supported by logical reasoning and, whenever possible, by experimental observations, measurements or analysis.

# Science Should Be Accessible

Modern scientific research often relies on sophisticated instruments that can cost thousands, millions, or even billions of dollars.

Those instruments have made remarkable discoveries possible, but they are beyond the reach of most independent researchers.

One of the goals of this project is to demonstrate that meaningful scientific investigation does not always require expensive laboratory equipment.

Most of the measurements presented in this repository were performed using instruments costing only **a few tens of US dollars**.

Some of the earliest experiments were carried out using equipment built almost entirely from recycled materials at virtually **no cost**.

This is something I am particularly proud of.

Curiosity, careful observation, logical thinking and reproducible methodology should never be limited by the size of a research budget.

If someone with basic technical skills can reproduce these experiments from home, then one of the most important goals of this project has already been achieved.

# Repository Structure

This repository is organized into several sections, each documenting a different part of the research.

## 📖 Book

Contains the manuscript of **Measurable Science**.

The book presents the theoretical model, the reasoning behind it, experimental observations, analyses and conclusions developed throughout the project.

---

## ⚙️ Equipment

Documents every measurement system used during the research.

This section includes:

- equipment descriptions
- technical specifications
- connection instructions
- photographs
- practical recommendations
- recording hardware
- software used for data acquisition

It also documents the evolution of the equipment—from a simple hand-wound induction coil to modern digital sensors.

---

## 📍 Locations

Contains documentation for every measurement location used throughout the project.

Each documented location may include:

- GPS coordinates
- photographs of the measurement site
- altitude
- date and time of the measurements
- local environmental conditions
- notes about nearby infrastructure or possible sources of interference
- links to the datasets recorded at that location

Careful documentation of measurement locations allows future experiments to be reproduced and compared under similar conditions.

---

## 🧪 Methodology

Describes exactly how every measurement was performed.

This section includes:

- experimental procedures
- field measurements
- calibration methods
- recording conditions
- recommendations for reproducing the experiments

The objective is to make every experiment as reproducible as possible.

---

## 🧮 Models

Contains the theoretical models developed throughout the research.

These documents explain the concepts presented in the book using logical, conceptual and mathematical descriptions.

---

## 📚 References

Contains the scientific references used throughout the project.

Instead of using a traditional bibliography, each referenced scientific statement links directly to its own documentation page containing:

- original publications
- supporting literature
- additional notes
- where the reference is used in the book

---

## 💻 Scripts

Contains the software developed for the project.

This includes:

- data acquisition
- signal processing
- data analysis
- visualization
- utility software

Most programs are written in Python and are intended to allow others to reproduce every stage of the analysis.

# Community Research

This repository is not intended to be a finished work.

It is intended to become an open research project.

If you reproduce any experiment described in this repository, I encourage you to share your results.

Positive, negative and inconclusive results are all valuable.

You are welcome to contribute:

- measurement datasets
- field recordings
- photographs of experimental setups
- improvements to the methodology
- analysis software
- corrections
- alternative explanations
- new experiments inspired by this work

Independent verification is one of the foundations of science.

The more people who repeat these measurements under different conditions, using different equipment and in different locations around the world, the more valuable the results become.

Whether your measurements support or contradict the conclusions presented here, they are welcome.

Every carefully documented experiment helps improve our understanding.

---

# Open Science

Everything contained in this repository is published openly.

You are encouraged to:

- inspect the measurements
- examine the methodology
- reproduce the experiments
- verify the analyses
- challenge the conclusions
- improve the methods
- continue the research independently

No claim presented here should be accepted simply because it is written in a book.

Likewise, no idea should be rejected without careful examination.

Science progresses through observation, measurement, logic and open discussion.
