# Hand-Wound Induction Coil

## Introduction

The hand-wound induction coil was the first measurement system developed for the **Measurable Science** project.

One of the main goals of this project has always been to demonstrate that meaningful scientific experiments do not necessarily require expensive laboratory equipment.

Many of the earliest measurements were performed using a coil built from recycled materials and connected directly to an ordinary computer sound card.

Even today, this remains one of the simplest and least expensive ways to begin experimenting with extremely low-frequency signals.

---

# Advantages

- Extremely inexpensive
- Can often be built entirely from recycled materials
- No specialized electronics required
- Excellent educational tool
- Ideal for learning basic signal recording and analysis

---

# Materials

Most users can build this system using materials they already have.

Typical components include:

- insulated copper wire
- quartz crystal (recommended)
- plastic tube
- cardboard tube
- PVC pipe
- wooden dowel
- old audio cable
- computer with an audio interface

The coil may be wound around any electrically non-conductive cylindrical object.

Quartz crystals were used during the original experiments, but they are not required for constructing the coil itself.

---

# Audio Interface

The only critical requirement is the audio interface.

Many modern sound cards include an internal high-pass filter that removes frequencies below approximately **20 Hz**.

Such devices are unsuitable for low-frequency measurements.

Older laptops and external audio interfaces often perform significantly better in this frequency range.

---

# Recording Software

The earliest recordings were performed using standard audio recording software.

Recommended software includes:

- Audacity
- Python recording scripts (available in this repository)
